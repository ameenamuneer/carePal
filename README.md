# CarePAL - AI-Powered Bedside Assistant

CarePAL is a complete healthcare monitoring system designed for elderly and chronically ill patients.

## Project Structure

- `backend/`: Django REST Framework application (Python)
- `carepal_app/`: Flutter mobile application (Dart)
- `docker-compose.yml`: Infrastructure orchestration

## Prerequisites

- Docker & Docker Compose
- Flutter SDK
- Python 3.10+
